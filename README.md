# Enterprise Network Architecture & Cisco Automation Labs 🌐⚡

Welcome to my central repository for Cisco Enterprise Infrastructure, Collaboration Systems, and NetDevOps Automation. This repository documents real-world routing/switching designs, Cisco IOS-XE configurations, and Netmiko/RESTCONF scripts tailored for Enterprise Architecture (**350-401 ENCOR**, **300-420 ENSLD**), Collaboration Solutions (**350-801 CLCOR**), and Networking Fundamentals (**200-301 CCNA**).

---

## 📚 Repository Structure & Modules

* 🔹 **`01-routing-and-switching/`**: BGP, OSPFv3, Spanning Tree, and VRF-Lite baseline configs (**200-301**, **350-401**).
* 🔹 **`02-network-design/`**: High Availability, SD-WAN topologies, and dual-homed WAN designs (**300-420**).
* 🔹 **`03-collaboration/`**: SIP Trunking, Call Routing, and Cisco Unified Communications Manager notes (**350-801**).
* 🔹 **`automation/`**: Python scripts for network inventory management and RESTCONF device queries.
